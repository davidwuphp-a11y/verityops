# Contributing

Describe the business rule and the observable authoritative records behind a proposed change. For a bug, provide a synthetic regression input, expected verdict and actual verdict. Keep negative and inconclusive controls intact. Run both suites in [TESTING.md](TESTING.md) and explain any intentional changes to reported outcomes.

Submit only work you own or have permission to contribute under the Apache License 2.0. Identify third-party material and its original license before including it. Exclude credentials, customer records, internal correspondence and generated run directories. For sensitive issues, follow [SECURITY.md](SECURITY.md).
